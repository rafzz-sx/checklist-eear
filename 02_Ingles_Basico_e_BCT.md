## ✈️ Vocabulário Aeronáutico Essencial para BCT & Falsos Cognatos EEAR

### Top Falsos Amigos (False Friends) Recorrentes:
- **Actually:** Na verdade, realmente *(NÃO é atualmente -> currently)*
- **Anticipate:** Prever, esperar *(NÃO é antecipar -> bring forward)*
- **Attend:** Assistir, comparecer *(NÃO é atender -> help, answer)*
- **Comprehensive:** Abrangente, completo *(NÃO é compreensivo -> understanding)*
- **Eventually:** No final das contas, por fim *(NÃO é eventualmente -> occasionally)*
- **Notice:** Notar, aviso *(NÃO é notícia -> news)*
- **Pretend:** Fingir *(NÃO é pretender -> intend)*
- **Resume:** Recomeçar, retomar *(NÃO é resumir -> summarize)*

### Termos Aeronáuticos Comuns na Prova de BCT:
- *Air Traffic Controller (ATCO)*: Controlador de Tráfego Aéreo
- *Runway (RWY)*: Pista de pouso e decolagem
- *Taxiway (TWY)*: Pista de táxi
- *Approach / Departure*: Aproximação / Saída
- *Altimeter setting / Altitude*: Ajuste de altímetro / Altitude
- *Clearance*: Autorização de tráfego
- *Wind shear / Turbulence*: Tesoura de vento / Turbulência
- *Visibility / Ceiling*: Visibilidade / Teto meteorológico
- *Touchdown*: Toque na pista (pouso)
- *Go-around*: Arremetida
